# Telegram MTProto Proxy for Railway 🚀

پروژه بهینه‌سازی شده و آماده برای استقرار پروکسی تلگرام ضد فیلتر (**MTProto v2 با Fake-TLS**) روی پلتفرم ابری **Railway**.

---

## ✨ ویژگی‌های کلیدی
- **سبک و فوق‌العاده کم‌مصرف:** مبتنی بر `mtg:2` با مصرف رم زیر ۲۰ مگابایت.
- **ضد فیلتر (Fake-TLS):** پشتیبانی از استاندارد `ee...` و جعل ترافیک به سمت دامنه امن (پیش‌فرض `google.com`).
- **اتصال آنی و بدون تاخیر (Fast Route):** تنظیم پیش‌فرض روی `prefer-ipv4` جهت جلوگیری از تاخیر اتصال به دیتاسنترهای تلگرام.
- **پشتیبانی از کلاستر و چند اکانته:** امکان استقرار روی چندین حساب مختلف ریل‌وی بدون تداخل.
- **ابزار وب داخلی:** شامل صفحه `index.html` برای مدیریت چند سرور، ساخت سکرت تصادفی، تولید QR Code آفلاین و کپی لیست سرورها.

---

## 🛠 نحوه استقرار سریع در Railway

### ۱. بارگذاری روی GitHub
فایل‌های این پروژه را روی یک مخزن گیت‌هاب (عمومی یا خصوصی) قرار دهید.

### ۲. اتصال به Railway
1. وارد [Railway.app](https://railway.app) شوید.
2. روی **New Project** ➔ **Deploy from GitHub repo** کلیک کرده و مخزن را انتخاب کنید.

### ۳. فعال‌سازی TCP Proxy (بسیار مهم)
1. وارد تب **Settings** در سرویس ایجاد شده شوید.
2. به بخش **Networking** رفته و روی دکمه **Add TCP Proxy** کلیک کنید.
3. یک آدرس هاست و پورت به شما داده می‌شود (مثال: `roundhouse.proxy.rlwy.net:12345`).

### ۴. دریافت لینک اتصال
لینک اختصاصی تلگرام شما به شکل زیر است:
```text
https://t.me/proxy?server=آدرس_هاست&port=شماره_پورت&secret=eed34e5658e41a995252834b92b6a95f7c676f6f676c652e636f6d
```
*(به جای `آدرس_هاست` و `شماره_پورت` مقادیر دریافتی از مرحله ۳ را قرار دهید).*

## ⚙️ متغیرهای محیطی قابل تنظیم (Environment Variables)

در تب **Variables** در پنل Railway می‌توانید هر یک از متغیرهای زیر را به دلخواه تنظیم کنید:

| متغیر | مقدار پیش‌فرض | توضیحات |
|---|---|---|
| `SECRET` | `eed34e5658e41a995252834b92b6a95f7c676f6f676c652e636f6d` | سکرت Fake-TLS |
| `PORT` | `443` | پورت داخلی سرور (به صورت خودکار توسط ریل‌وی مدیریت می‌شود) |
| `PREFER_IP` | `prefer-ipv4` | اولویت اتصال به تلگرام (`prefer-ipv4` یا `prefer-ipv6`) |
| `CONCURRENCY` | `8192` | حداکثر تعداد اتصالات همزمان |
| `DEBUG` | `false` | لاگ‌های با جزئیات بیشتر برای دیباگ |

## 🔄 اجرای همزمان روی چند اکانت (High Availability & Load Balancing)
1. همین مخزن را در هر تعداد حساب کاربری Railway که دارید دیپلوی کنید.
2. پورت و هاست هر اکانت را در فایل `index.html` ذخیره کنید.
3. تمام لینک‌ها را به تلگرام خود اضافه نمایید. تلگرام همیشه بهینه‌ترین و سریع‌ترین سرور را انتخاب می‌کند.
